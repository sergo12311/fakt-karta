# Факт-карта — как вносить изменения

Статический сайт на GitHub Pages: https://sergo12311.github.io/fakt-karta/
Всё приложение — один файл `index.html` (HTML + CSS + JS), плюс `sw.js` для офлайн-режима.
Сборки нет: что лежит в ветке `main`, то через 1–2 минуты и на сайте.

## Выпуск новой версии (каждый раз)

1. Внести правку в `index.html`.
2. Поднять версию (например 3.0 → 3.1) в трёх местах, иначе телефоны не подхватят обновление:
   - `index.html`: `const APP_VERSION = '…'`
   - `index.html`: новая запись в начале списка изменений сразу под ним — `{ v: '…', date: '…', items: [ … ] }` (по-русски, коротко, что поменялось для пользователя)
   - `sw.js`: комментарий в первой строке и `const CACHE = 'fakt-karta-…'`
3. Проверить, что страница открывается без ошибок в консоли.
4. Коммит с сообщением вида `v3.1: кратко что изменилось`, push в `main`.
5. Скопировать обновлённые файлы в папку пользователя на компьютере `C:\Users\Sergey\Desktop\fakt-karta-site`, если она подключена.
